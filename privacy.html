Privacy by
design.

This starter implementation stores calculator results, challenge progress and profile details in your browser's local storage unless you explicitly configure cloud services.

Local browser storage

The current calculator stores your latest result under a browser-local key. Profile and challenge progress are also stored locally. Clearing browser site data may remove these records. Other people using the same browser profile may be able to access locally stored information.

Cloud accounts

Supabase authentication and database features are optional and are not active until a project is configured. If enabled, account data is processed by your configured Supabase project under its policies and your applicable privacy obligations.

Leaderboard participation

Campus rankings should be opt-in. Use a display name or alias and do not publish email addresses, student IDs or detailed personal activity records.

Contact and responsibility

Before public deployment, add the project owner's contact details, a data-retention policy, deletion process and jurisdiction-specific privacy disclosures. This page is a project template, not legal advice.
