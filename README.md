# CarboTrack

A campus-focused carbon footprint calculator and sustainability dashboard built with HTML, CSS, vanilla JavaScript, Tailwind CSS, Chart.js and Supabase.

## Run locally

Open `index.html` in a local web server (for example, VS Code Live Server). Configure Supabase in `js/config.js` to enable cloud authentication and persistence. The calculator works locally without Supabase.

## Features
- Personal carbon footprint calculator
- Emissions breakdown, score and practical recommendations
- Dashboard, challenge tracker and leaderboard-ready data model
- Responsive accessible interface

See `SETUP.md` for configuration and database setup.
